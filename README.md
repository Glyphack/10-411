# 10-411 Compilers for Machine Learning

This folder is the reference for my project of building an ML compiler from scratch, following the CMU course 10-411.

It holds AI written learning material and the build plan. Everything here must be based on the course and its spec:

- [10-411 course page](https://10-411.com/): the course.
- [Technical syllabus by geohot](https://gist.github.com/geohot/4768597d9dc536446ee2d5de1f29e89d): the ops for each week and the `.uir` format.
